# STEP 31 — Decision Engine v1

The Digital Twin now has a lightweight decision-engine layer that turns Frits's documented professional principles into grounded action frameworks.

It supports question types such as:
- customer complaints
- commercial offers
- customer prioritization
- AI automation
- problem solving
- learning from human feedback
- human value / empathy

The engine only uses documented Knowledge Base principles. It does not invent thresholds, policies, experience, or hidden reasoning.

Example:
"Hoe zou Frits AI inzetten in een klantenserviceproces?"
→ problem/automation classification
→ grounded sequence of actions
→ Claude turns that into a natural conversational answer.
